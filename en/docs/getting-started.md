# How to Use the Repository

This section describes how to search for code and how to contribute your own work to the database.

## Searching for Code

1. Use the **Retype search bar** in the top right corner.
2. Or navigate to the desired category using the sidebar menu.

## How to Contribute Code (Contributing)

If you have a useful GPL-licensed module or script you would like to share:

1. **Fork** this repository.
2. Create a file with a description and code in the appropriate folder inside `en/` (and its counterpart inside `docs/` for the Russian version).
3. Ensure the code contains a header specifying ownership and the GPL license.
4. Submit a **Pull Request**.

[!badge variant="warning" text="Important"] Make sure the added code is truly compatible with the GPL license and does not violate third-party copyrights.
